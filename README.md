# Classification-FOCH-Finals

Ici reposent mes meilleurs notebooks de test sur la base de données de Foch. J'implémente les mêmes structures que les autres notebooks dans mon repo `Classification-FOCH-Test`.

## Contenu
- Notebooks Jupyter (.ipynb) contenant des expériences et analyses pour la base de données Foch.

## Utilisation
1. Cloner le dépôt :

   ```bash
   git clone https://github.com/ca1m1ejaune/Classification-FOCH-Finals.git
   cd Classification-FOCH-Finals
   ```

2. Installer un environnement Python (recommandé) :

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # macOS / Linux
   .venv\Scripts\activate    # Windows
   pip install --upgrade pip
   ```

3. Installer les dépendances usuelles pour exécuter les notebooks :

   ```bash
   pip install jupyter pandas numpy scikit-learn matplotlib seaborn notebook
   ```

4. Lancer Jupyter Notebook / Lab et ouvrir les fichiers .ipynb :

   ```bash
   jupyter notebook
   # ou
   jupyter lab
   ```

## Données
Les jeux de données ne sont pas inclus dans ce dépôt par défaut. Placez les fichiers de données au même niveau que les notebooks ou suivez les instructions spécifiques dans chaque notebook.

## Structure et conventions
- Chaque notebook suit les mêmes structures et conventions que celles du dépôt `Classification-FOCH-Test` (prétraitement, entraînement, évaluation, visualisation).
